# ⚙ Prerequisites

Install the following software before running the projects.

- Java 17+
- Maven 3.8+
- Node.js (React)
- npm
- Git
- Oracle Database / MySQL (where applicable)
- IntelliJ IDEA / Eclipse / VS Code

Verify installation

```bash
java -version

mvn -version

node -v

npm -v

git --version
```

# ▶ Running Java Projects

Compile

```bash
mvn compile
```

Package

```bash
mvn package
```

Run Tests

```bash
mvn test
```

Run Spring Boot

```bash
mvn spring-boot:run
```

---

# ▶ Running React Projects

Move into the desired React exercise.

```bash
cd React/"Exercise Folder"
```

Install dependencies

```bash
npm install
```

Run

```bash
npm start
```

Production Build

```bash
npm run build
```
