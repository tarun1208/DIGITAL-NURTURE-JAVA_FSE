# 📖 Overview

This folder contains my **hands-on React learning journey** completed during the **Digital Nurture Java Full Stack Engineering Program**.

Instead of building one large application, this repository contains **19 independent React exercises**, where each project focuses on a specific React concept. These exercises helped me understand modern frontend development, component-based architecture, state management, event handling, conditional rendering, forms, routing concepts, and reusable UI development.

Each exercise is a standalone React project with its own dependencies and can be executed independently.


# ▶️ Running Any Exercise

Move into the required exercise folder.

Example:

```bash
cd "11th Exercise - React"
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```

Open your browser:

```
http://localhost:3000
```
