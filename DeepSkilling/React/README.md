# 📖 Overview

This directory contains my hands-on React learning journey completed as part of the **Digital Nurture Java Full Stack Engineering Program**.

Instead of building a single application, this folder contains multiple independent exercises that progressively cover React fundamentals, component-based architecture, event handling, state management, conditional rendering, forms, styling, and practical UI development.

Each exercise focuses on a specific concept commonly used in modern frontend development.
